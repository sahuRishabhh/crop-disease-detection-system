# Model Evaluation Outputs & Verification Metrics

This directory contains evaluation artifacts, classification metrics, training loss/accuracy curves, and confusion matrices generated by the training and evaluation pipelines.

---

## 1. Directory Artifacts

| File | Description |
| :--- | :--- |
| `metrics.json` | Quantitative evaluation metrics on the held-out test split (accuracy, precision, recall, F1-scores, latency) |
| `confusion_matrix.png` | Visual confusion matrix plot across all 9 target classes |
| `training_curves.png` | Training vs. validation loss and accuracy trajectories over epochs |
| `training_history.json` | Epoch-by-epoch training telemetry, validation metrics, and duration |

